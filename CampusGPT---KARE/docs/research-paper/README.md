**Campus-GPT: A Policy-Aware and Privacy-Preserving AI Assistant for Personalized University Decision Support**

## Locked decisions reflected in this draft
- Working **prototype** (not experimentally proven superiority)
- **No invented** latency / Precision@K / accuracy %
- Evaluation = functional + security scenarios + **future methodology**
- Heuristic confidence (~0.95 / ~0.85 / ~0.3) + θ=**0.7** (never called “accuracy”)
- Contribution: dual UIS+AI + consent/ABAC + RAG/personal data (+ multi-agent)
- Scope: **general framework**, demonstrated at **KARE** (limited specifics)
- Figures: architecture diagrams only (UI screenshots not included yet)
- Balanced research + implementation writing
